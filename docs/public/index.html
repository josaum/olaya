Core Architecture

Engineered for production software.

Standard LLMs burn compute pretending to be conversationalists. Leio is a dedicated mathematical decision engine.

🦀

Sub-Microsecond In-Browser WebAssembly

A standalone 189 KB WebAssembly binary running compiled Rust code directly in client memory or Cloudflare Workers. Zero network latency, zero per-decision cloud costs, and complete offline capability for edge devices.

✓ Tested on 730 DOID classes in 800 nanoseconds
🛡️

Formal Axiomatic Proofs

Category-theoretic exclusion kernels guarantee that mutually exclusive branches are algebraically zeroed (A ⊓ B = ⊥). Subsumption monotonicity guarantees that child classes never exceed parent probabilities.

✓ Zero hallucination guaranteed
💸

Unmetered Free Outputs

You only pay for input tokens at $0.042 per 1M. Returned decision classifications, probabilities, lineage breadcrumbs, and axiom verification objects are 100% free with zero output token tax.

✓ 250x cheaper than GPT-4o
📦

100,000+ Class Scalability

BM25 IDF candidate routing extracts localized sub-lattices on the fly, allowing Leio to scale gracefully to massive enterprise product catalogs, medical terminologies, and supply chain graphs.

✓ Sub-linear graph traversal

Zero-Install Agent Wedge
