Objection Handling · Technical FAQ

Frequently asked architecture questions.

Clear, direct answers for senior engineers, enterprise architects, and engineering leadership.

How can Leio be 250x cheaper than GPT-4o while making outputs 100% free?
Generative LLMs burn massive GPU compute generating dozens or hundreds of sequential tokens autoregressively. Leio is not a generative text writer; it is an ontology-grounded classification and category-theoretic reasoning kernel ($O(K)$ candidate generation + $O(1)$ transitive closures). Because output decisions are typed machine representations (CURIEs, probabilities, lineage breadcrumbs, and axiom proofs), there is zero token generation overhead — so outputs are 100% free and unmetered forever.
Does Leio replace our existing LLMs or work alongside them?
It works alongside them via Dual-Process architecture (Kahneman's System 1 and System 2). In autonomous software, 92% of operations (tool selection, intent triage, data routing, guardrail verification) require fast, deterministic decisions — not conversational prose. Leio handles the 92% System 1 fast path in < 1ms for micro-cents. When an observation genuinely requires open-ended synthesis or human-facing prose (the 8% System 2 slow path), Leio hands off pre-filtered context to your LLM, cutting agent latency by 85% and context token burn by 90%.
What does formal mathematical monotonicity P(A) ≤ P(B) actually guarantee?
In classical neural networks and LLMs, hierarchical contradictions are common: a model might predict "Angiosarcoma" with 95% confidence but classify "Malignant Neoplasm (Cancer)" at only 40%, breaking downstream database invariants and compliance rules. Leio's axiomatic subsumption head mathematically enforces $P(\text{child}) \le P(\text{parent})$ across all transitive relations in the directed acyclic graph (DAG). A child concept's probability can never exceed its parent's probability.
Can we run Leio completely air-gapped without outbound network calls?
Yes. Leio is designed from day one for zero-trust environments. The WebAssembly binary (189 KB) runs entirely in client-side RAM with zero external phone-home telemetry. For backend clusters, our statically linked native Rust binary or Docker image deploys directly inside your private VPC (AWS, GCP, Azure PrivateLink) or on-premise hardware with Zero Data Retention (ZDR).
How do we integrate Leio with our autonomous AI agents or microservices?
Integration takes under 30 seconds. For autonomous agents (Cursor, Claude Desktop, LangChain, AutoGen), run uvx olaya-mcp or npx @mycelia/olaya-mcp to expose Leio as a standard Model Context Protocol (MCP) tool. For microservices and backend systems, use our native Python SDK (pip install olaya) or call the high-throughput hosted edge HTTP endpoint at POST /api/systemone.
How long does custom enterprise ontology training take?
Unlike training large language models which takes weeks and millions of dollars, Leio compiles in minutes. Using our contrastive Atlas embedding pipeline and topological subsumption loss, custom enterprise taxonomies (e.g. 50,000 SKUs, custom support categories, internal infrastructure graphs) compile in under 15 minutes on a single GPU or CPU instance.
