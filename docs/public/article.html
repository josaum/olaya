STRUCTURED DECISION PRIMITIVES

Five primitives. Zero prose.

Instead of prompting an unconstrained language model with paragraphs of instructions, you formulate decisions using five mathematically rigorous primitives. 

from olaya import OLaya

olaya = OLaya()

state = {
    "gtin": "0614141000036",
    "scan_text": "Grade A pasteurized whole milk, 1 gallon jug with tamper-evident seal. Keep refrigerated at 34-38 F.",
    "sensor_temp_c": 3.2,
    "carrier": "ColdExpress Logistics",
}

questions = {
    "taxonomy_grounding": { "type": "concept", "root": "Product", "instructions": "Ground item into GS1 category." },
    "requires_cold_chain": { "type": "subsumes", "concept": "FoodBeverageTobaccoProduct", "instructions": "Perishable handling rules?" },
    "packaging_triage":   { "type": "choice", "criteria": {"pallet_return": "reusable wooden pallet", "corrugated_bale": "cardboard carton"} },
    "dock_urgency":       { "type": "score", "criteria": ["ambient_low", "standard_dock", "expedited_perishable_cold_chain"] },
    "seal_breach_alert":  { "type": "noul", "instructions": "Any indication of seal damage or temperature excursion?" }
}

result = olaya.system_one(state, questions)

1. concept

Leaf taxonomy grounding with guaranteed monotonicity: P(child) ≤ P(parent) everywhere. Returns full ancestral lineage with no broken category math.

P(Product) ≥ P(FoodBeverage) ≥ P(Milk)

2. subsumes

Tests whether the item belongs to the principal down-set ↓C of a target category. Enables instantaneous PLC diverter triggers without querying external clouds.

↓C = {x ∈ Ο | x ⊑ C}

3. choice

Evaluates mutually exclusive options with category-theoretic exclusion. If two classes are disjoint, their joint probability is strictly zero.

A ⊓ B = ⊥ &implies; P(A ∩ B) = 0

4. score & noul

Ordered ordinal calibration for priority queues, alongside binary out-of-domain anomaly gating to catch sensor excursions and unknown SKUs.

E[Y] = ∑ i · P(level_i)
